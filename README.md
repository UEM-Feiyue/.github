# 应急管理大学飞跃手册 | UEM Feiyue

应急管理大学飞跃手册是由校友自发建设与维护的开源社区，记录并分享升学与职业发展中的真实经历，让走过的路成为后来者的参考。

[访问飞跃手册](https://uem-feiyue.github.io/) · [投稿分享](https://uem-feiyue.github.io/submit.html) · [共建与联系](https://uem-feiyue.github.io/community.html) · [网站源码](https://github.com/UEM-Feiyue/UEM-Feiyue-Site-Source)

## 共建与联系

欢迎更多同学和校友参与飞跃手册的建设。无论是分享考研、留学、就业或考公考编经历，整理内容、联系校友、宣传推广，还是参与网站开发与日常维护，都可以为后来者留下有价值的参考。

如有参与意向、意见建议、内容纠错或合作想法，欢迎通过 [邮件](mailto:hello@futseyi.com) 联系我们，也可以通过 [网站源码仓库](https://github.com/UEM-Feiyue/UEM-Feiyue-Site-Source) 参与项目。

## 手册维护者

感谢每一位参与建设、维护和经验分享的校友。
